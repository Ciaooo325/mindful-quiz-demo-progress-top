明知故問 Initial 五題手機版網頁 Demo

1. 使用 VS Code 開啟本資料夾。
2. 使用 Live Server 或 python -m http.server 8000 預覽。
3. 將背景圖放進 assets/backgrounds/：
   forest-default.jpg、forest-a.jpg、forest-b.jpg、forest-c.jpg、forest-d.jpg
   ocean-default.jpg、ocean-a.jpg、...、sky-d.jpg
4. 將選項圖片放進 assets/options/：
   forest-a.png、forest-b.png、forest-c.png、forest-d.png
   ocean-a.png、...、sky-d.png
5. 在 script.js 的 questions 修改題目與選項文字。
6. 目前結果頁只顯示答案與分數，未套用正式推薦演算法。
7. 圖片建議：背景直式 1080×1920 JPG；選項 PNG 透明底，建議 500×450 左右。
8. 不要將個人資料放進公開的 GitHub 儲存庫。
